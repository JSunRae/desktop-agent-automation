# Copilot Agent Instructions

## Orientation

### Repository Context

This repository implements a desktop automation system for AI agents, focusing on task management, feedback loops, and cross-platform desktop interactions. The core automation handles VS Code interactions, panel management, and agent coordination.

### Key Files to Review

- `README.md`: Project overview and setup
- `docs/ARCHITECTURE.md`: System architecture
- `automation/config.py`: Configuration management
- `automation/master_prompt_orchestrator.py`: Core orchestration logic
- `agent_assignments.json`: Task ledger (see AGENTS.md for details)
- `schemas/agent_tasks.schema.json`: Task schema definition

### Architectural Overview

The system consists of:

- **Automation Core**: Handles desktop interactions and VS Code automation
- **Task Management**: JSON-based task tracking with CLI tools
- **Feedback Loop**: Metrics collection and analysis for continuous improvement
- **Panel Tracking**: UI element detection and management
- **Rate Limiting**: Prevents API abuse and manages costs

## Setup/Build/Test/Deploy

### Prerequisites

- Python 3.8+
- Windows environment (primary target)
- VS Code with Python extension
- Git for version control

### Setup Commands

```bash
# Clone repository
git clone <repo-url>
cd desktop-agent-automation

# Create virtual environment
python -m venv .venv
.venv\Scripts\activate  # Windows

# Install dependencies
pip install -r requirements.txt

# Run setup validation
python scripts/validate_agent_tasks.py --summary
```

### Build/Test Commands

```bash
# Run tests
python -m pytest tests/ -v

# Run specific test
python -m pytest tests/test_cost_tracker.py -v

# Validate task system
python scripts/validate_agent_tasks.py

# Run automation
python master.py
```

### Deploy Commands

```bash
# Package for distribution
python -m build

# Install locally
pip install -e .
```

### Style Guide

- Follow PEP 8 Python style

- Use descriptive variable names

### Logging Practices

- Use Python's logging module

- Include context in log messages
- Avoid print statements in production code

### Error Handling

- Use try/except blocks for expected errors

- Separate concerns into modules

## Agent Workflow

### Task Claiming

1. Review available tasks in `agent_assignments.json`
2. Claim task using CLI: `python scripts/tasks_cli.py claim --id <task-id> --by agent:github-copilot`
3. Update task status to `in_progress`

### Working Process

1. Understand task requirements from description
2. Review relevant code and documentation
3. Implement changes following standards
4. Test changes locally
5. Update task with progress notes

### Verification Steps

1. Run relevant tests
2. Validate code against linting rules
3. Test functionality manually if needed
4. Update task status to `review` or `completed`

### Handoff Process

1. Add final notes with artifacts
2. Update task status to `completed`
3. Suggest commit message
4. Document any follow-up tasks

### Task Management Integration

- All work must be tracked in the task ledger
- Use CLI tools for status updates
- Maintain detailed notes with timestamps
- Reference artifacts in task notes

### Conflict Resolution

- Check task status before starting work
- Communicate with other agents via task notes
- Escalate conflicts to human assignees
- Use `blocked` status for dependencies

This guidance ensures consistent, high-quality contributions while maintaining system integrity and audit trails.
